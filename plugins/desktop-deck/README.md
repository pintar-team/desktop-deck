# Desktop Deck plugin

Control the local Desktop Deck macOS app from Codex or Claude Code. The plugin provides screenshots, remote keyboard and pointer input, connection management and shared SSH terminal tabs. Install the application first, open it, then install this plugin through the repository's local marketplace. No server addresses or credentials are bundled. Human input has priority. Read the control skill before operating a desktop or terminal; reconnect never replays commands.

After adding the local marketplace, use `claude plugin install desktop-deck@desktop-deck-local` or `codex plugin add desktop-deck@desktop-deck-local`. The repository installer performs those steps through the supported client commands.
